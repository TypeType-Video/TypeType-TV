TypeType TV now updates itself.

- When a new version is published, an Update button appears in the top bar. It shows what the new version
  brings, then downloads it, checks its checksum, and hands it to the Android installer.
- Settings > Updates checks right away, switches between the stable and beta channels, and turns off the check
  made when the app opens.
- The check asks GitHub, where TypeType TV is published, when the app opens and every few hours while it stays open.

Versions before this one cannot update themselves: install this one by hand once, and the next ones are offered
in the app.

Download `TypeType-TV-v0.2.0.apk` below; the `.sha256` file lets you check the download.

Betas are published as prereleases. A beta installs over the stable release, and the next stable release installs
over the beta.
