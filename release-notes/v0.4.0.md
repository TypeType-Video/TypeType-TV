Browse your subscriptions, and connect to instances that only speak HTTP.

- A new Subscriptions tab, between Home and Search: the latest videos from the channels you follow, loaded page by
  page, and the list of those channels. OK on a channel opens it.
- Instances that only answer over plain HTTP now work: type `http://` before the address. The setup screen warns
  that HTTP does not encrypt your account data, and tells you to add `http://` when a server only answers over HTTP.
- The startup intro is much smoother on slower boxes, and its sound stays in time with the picture.

Download `TypeType-TV-v0.4.0.apk` below; the `.sha256` file lets you check the download.

Betas are published as prereleases. A beta installs over the stable release, and the next stable release installs
over the beta.
